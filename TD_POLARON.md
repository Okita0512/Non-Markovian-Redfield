# Constant-bias time-dependent polaron NZ2 benchmark

This implementation adds the time-dependent (TD) polaron master equation of
Nuomin *et al.* to the classic spin-boson benchmark set already included in
this repository.  It intentionally uses a **constant system Hamiltonian**; no
Landau-Zener sweep is introduced.

## Hamiltonian and notation

The solver uses

\[
H=\frac{\epsilon_b}{2}\sigma_z+V\sigma_x
 +\sigma_z\sum_k g_k(b_k+b_k^\dagger)
 +\sum_k\omega_k b_k^\dagger b_k,
\]

with \(\hbar=k_B=1\).  The older model files in this repository use

\[
H_S=\epsilon\sigma_z+\Delta\sigma_x,
\]

so the adapter maps

\[
\epsilon_b=2\epsilon,\qquad V=\Delta.
\]

The legacy bath correlation function contains
\(c_k^2/(8\omega_k)\).  Therefore the equivalent bosonic coupling in the
TD-polaron convention is

\[
g_k=\frac{c_k}{\sqrt{8\omega_k}}.
\]

This mapping preserves the bath discretization already used by
`Models/SpinBoson_Ohmic.py` and `Models/SpinBoson_Debye.py`.

## Implemented equation

The identity-initialized displacement gives

\[
\eta_k(t)=\frac{g_k}{\omega_k}\left(1-e^{-i\omega_k t}\right),
\]

and the mean transformed Hamiltonian is

\[
H_m(t)=\frac{\epsilon_b}{2}\sigma_z+Vm(t)\sigma_x,
\qquad
m(t)=e^{-4F(t)}.
\]

For the discrete bath,

\[
F(t)=\sum_k\frac{g_k^2}{\omega_k^2}
\coth\!\left(\frac{\beta\omega_k}{2}\right)
[1-\cos(\omega_k t)],
\]

\[
G(t)=\sum_k\frac{g_k^2}{\omega_k^2}\sin(\omega_k t).
\]

The code evaluates the nonstationary connected correlation functions
\(C_{\mu\nu}(t,t')\) and propagates the second-order time-nonlocal
Nakajima-Zwanzig equation in the interaction picture of \(H_m(t)\).  The mean
propagator uses a midpoint exponential.  The memory integral uses trapezoidal
quadrature, and the Volterra equation uses a second-order Heun
predictor-corrector.

For direct control calculations, the same solver also implements the static
polaron mean and stationary correlations.

## Running a benchmark

From the repository root:

```bash
python run_tdpolaron.py --model 8 --method td
```

To compare TD and static polaron frames in a quicker exploratory run:

```bash
python run_tdpolaron.py \
  --model 8 --method both --dt 0.01 --tmax 5 --plot
```

A legacy-format HEOM, MPS, QUAPI, or other reference trajectory can be
overlaid and scored directly:

```bash
python run_tdpolaron.py \
  --model 8 --method both \
  --reference path/to/reference_rhot.txt --plot
```

The reference text format is the one already used by `run.py`: time followed
by the real and imaginary parts of `rho00`, `rho01`, `rho10`, and `rho11`.  A
CSV reference with columns named `time` and `sigma_z` is also accepted.  The
JSON output records the maximum absolute and RMS `sigma_z` errors over the
common time window.

Available model numbers are 3-19, matching the comments in the existing
Ohmic and Debye model files.  Output is written to `Results/TDPolaron/`:

- `*.txt`: the same row-major real/imaginary density-matrix format used by
  `run.py`;
- `*.csv`: polaron-frame density matrix, \(\langle\sigma_z\rangle\), trace,
  minimum density eigenvalue, and \(m(t)\);
- `*.json`: parameters and numerical diagnostics;
- an optional comparison PNG.

The original production time steps make the full nonstationary memory
calculation expensive because the direct algorithm scales as
\(O(N_t^2)\).  The default `--backend auto` uses a Numba-compiled memory
kernel when Numba is installed and otherwise falls back to NumPy.  The first
Numba run includes JIT compilation overhead.  Coarser `--dt` and `--tmax`
values are useful for initial checks.  Converged calculations should be
repeated with successively smaller `dt`.

## Numerical checks

Run

```bash
python -m unittest discover -s tests -v
```

The tests verify:

1. zero coupling reproduces isolated two-level dynamics;
2. the TD interaction vanishes at the initial time;
3. trace and Hermiticity are preserved in a short calculation;
4. TD and static frames coincide at zero coupling;
5. the legacy benchmark registry and Hamiltonian convention are consistent.

## Frame convention for observables

The solver propagates the reduced density matrix in the selected TD- or
static-polaron frame and then returns to the Schrödinger picture generated by
`H_m(t)`.  Since the polaron transformation commutes with `sigma_z`, the
diagonal populations and \(\langle\sigma_z\rangle\) are unchanged by the
frame transformation and can be compared directly with laboratory-frame
reference trajectories.  The off-diagonal entries in the output remain
polaron-frame coherences.  Recovering laboratory-frame coherence requires a
back-transformation containing bath displacement operators and generally
requires an additional approximation.

## Scope and caveats

- The TD displacement is exact for the longitudinal harmonic spin-boson
  coupling.  The reduced equation remains a second-order Born expansion in
  connected transformed fluctuations.
- The natural initial state is factorized in the laboratory frame.  A
  correlated interacting-equilibrium preparation requires a different
  treatment.
- Complete positivity is not guaranteed.  The CSV/JSON diagnostics therefore
  report the minimum density-matrix eigenvalue.
- For finite bath discretizations, long-time recurrences are expected.
  Low-frequency modes also make the static Franck-Condon overlap strongly
  discretization dependent; in the continuum Ohmic or Debye limit it may
  vanish.  The finite-time TD functions are generally better behaved because
  `1-cos(omega*t)` regularizes the infrared contribution at any finite time.
- This code provides trajectories for direct comparison with HEOM, MPS, QUAPI,
  or other reference data, but those external reference trajectories are not
  bundled here.
